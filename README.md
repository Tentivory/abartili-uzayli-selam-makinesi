# Abartılı Uzaylı Selam Makinesi 🚀

**DİKKAT: Bu proje son derece ciddidir. Şaka değildir. Gerçekten değildir.**

## Amaç

Evrenin en büyük sorunlarından biri olan "nasıl selamlaşılır?" sorusuna kesin ve bilimsel çözüm getirmektir. Yıllarca süren araştırmalar (yaklaşık 3 dakika) sonucunda bu makine icat edilmiştir.

## Nasıl Çalışır?

1. Kodu indir.
2. `python selam.py` komutunu çalıştır.
3. Herhangi bir metin gir.
4. Uzaylıca selam al.
5. Hayatın anlamını bul (bulamazsın ama selam alırsın).

Bu makine, metni ters çevirip üzerine rastgele uzay sembolleri ekleyerek **%100 bilimsel** bir uzaylı selamı üretir. NASA onaylamamıştır çünkü çok ileri teknoloji.

## Özellikler

- Gerçekten çalışır.
- Sonsuz döngü potansiyeli.
- Dramatik bekleme süreleri.
- Çıkış seçeneği (isteğe bağlı üzüntü).
- Gizli mesajlar içerir (bulamazsın).

## Kurulum

```bash
git clone https://github.com/Tentivory/abartili-uzayli-selam-makinesi.git
cd abartili-uzayli-selam-makinesi
python selam.py
```

Python 3 yeterlidir. Başka bir şey gerekmez çünkü bu zaten abartılı.
